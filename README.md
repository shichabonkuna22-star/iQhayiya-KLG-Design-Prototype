# iQhayiya Design Workshop

Static prototype of the iQhayiya Design Workshop site. HTML, CSS and JS are served as-is (no bundler).

GitHub Pages:

- https://shichabonkuna22-star.github.io/iQhayiya-Design-Prototype/
- https://shichabonkuna22-star.github.io/iQhayiya-KLG-Design-Prototype/

Repos: [iQhayiya-Design-Prototype](https://github.com/shichabonkuna22-star/iQhayiya-Design-Prototype), [iQhayiya-KLG-Design-Prototype](https://github.com/shichabonkuna22-star/iQhayiya-KLG-Design-Prototype).

Copy, contact details, project facts, and photographs are from [iqhayiyadw.co.za](https://www.iqhayiyadw.co.za).

## Run locally

```bash
npm install
npm run dev
```

Then open http://127.0.0.1:43123/index.html
